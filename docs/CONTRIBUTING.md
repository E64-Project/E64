# Contributing to E64

E64 V1 has been released for independent community development.

The original E64 developer is stepping away from active development.
There is no commitment to future updates, maintenance, technical
support or review of contributions.

## Project Repository

https://github.com/E64-Project/E64

## Independent Development

Developers are encouraged to fork the repository, study the source,
make improvements and distribute their own versions in accordance
with the applicable licenses.

Future community maintainers may establish their own development
priorities, release schedules and contribution procedures.

## Development Guidelines

- Read BUILDING.md before compiling the firmware.
- Preserve original copyright and license notices.
- Keep changes focused and documented.
- Run the applicable regression tests.
- Identify which hardware configurations have been tested.
- Clearly distinguish modified releases from the original E64 V1.
- Do not include proprietary Commodore ROMs in distributions
  without appropriate redistribution rights.

## Project Maintenance

Community members are welcome to establish actively maintained
forks of E64.

Permission from the original E64 developer is not required to
exercise the rights granted by the applicable software licenses.
